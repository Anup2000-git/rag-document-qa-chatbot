# 🤖 RAG-Based Document Q&A Chatbot

A Retrieval-Augmented Generation (RAG) chatbot that answers questions **grounded in your own documents** (PDF, DOCX, TXT). Documents are chunked, embedded with Sentence-Transformers, indexed in **FAISS**, and the most relevant chunks are passed to **Google Gemini** to generate an answer.

## ✨ Features

- 📄 Ingests **PDF, DOCX and TXT** documents
- ✂️ Text chunking + **all-MiniLM-L6-v2** embeddings
- ⚡ Fast semantic search with a **FAISS** vector index
- 🧠 Answers generated by **Gemini 1.5 Flash**, restricted to the retrieved context (reduces hallucination)
- 🌐 Two interfaces: a **FastAPI** REST endpoint and a **Streamlit** chat UI with dark mode

## 🏗️ Architecture

```
Documents ──► Chunking ──► Embeddings (MiniLM) ──► FAISS Index
                                                     │
User Question ──► Embed ──► Top-k Similarity Search ─┘
                                   │
                         Retrieved Context + Question
                                   │
                            Gemini 1.5 Flash ──► Answer
```

## 📁 Project Structure

```
RAG_Chatbot/
├── data/documents/   # Source documents (PDF, DOCX, TXT)
├── db/               # FAISS index + chunk metadata
├── ingest.py         # Load → chunk → embed → build FAISS index
├── query_engine.py   # Retrieve top-k chunks and query Gemini
├── utils.py          # Document loaders and text chunking
├── app.py            # FastAPI endpoint  (GET /query)
└── app_ui.py         # Streamlit chat interface
```

## 🚀 Getting Started

```bash
cd RAG_Chatbot
pip install -r requirements.txt

# Add your Gemini API key
cp .env.example .env        # then edit GEMINI_API_KEY

# 1. Build the vector index from data/documents/
python ingest.py

# 2a. Run the Streamlit UI
streamlit run app_ui.py

# 2b. Or run the REST API
uvicorn app:app --reload
# → http://127.0.0.1:8000/query?question=What is RAG?
```
